Privacy Policy

Last updated: October 15, 2026.

Project status

GoNews Publisher is an experimental, not-yet-deployed code prototype and informational static site. The website currently provides no account login, video uploading, or posting service.

Data on this website

We do not intentionally collect TikTok passwords, OAuth tokens, video files or account information through this website. The website host, GitHub Pages if enabled, may automatically process technical request data such as IP addresses according to its own policies.

Future TikTok functionality

A future version may allow the authorized account owner to connect TikTok through OAuth. It would need to process account identifiers, OAuth access and refresh tokens, selected MP4 files, captions, and publication statuses solely to provide owner-approved publishing. These functions are not active on this site. Before a live service launches, this policy will be updated with accurate data storage, retention, deletion and contact details.

Third parties

The project source is hosted on GitHub. A future posting service would use TikTok's official API. Never submit passwords, API secrets or authentication tokens on this site or in public GitHub issues.

Questions

Project information is available at the repository. No public contact form is offered. This notice describes the current prototype, not a launched service.

Independent prototype, not affiliated with TikTok.
