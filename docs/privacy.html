Privacy Policy

Updated: October 15, 2026.

Current service status

GoNews Publisher is an experimental project, currently intended for the owner of TikTok account @g0news1 rather than general public use. The public GitHub Pages website is informational: it does not itself collect TikTok passwords, accept MP4 uploads or publish videos. A separate Cloudflare Worker at gonews-tiktok-auth.daniloflores835.workers.dev hosts the development OAuth connection service. The Worker may process authorization data when the owner explicitly connects TikTok; no live video publishing service has launched.

Data handled during account authorization

If you use the TikTok connection flow, TikTok supplies an authorization code, an account identifier, access and refresh tokens, granted permissions, and token expiry metadata. The service requests user.info.basic to help identify the connected account and video.publish to prepare an authorized posting integration. The account username may be queried from TikTok to check that the correct account has been connected. TikTok passwords are not requested by our service.

Storage and protection

The Worker uses Cloudflare Workers KV to store the account authorization and token metadata encrypted with AES-GCM using a key configured separately in Cloudflare Secrets. A temporary one-time OAuth state is kept in KV for no longer than approximately ten minutes and is deleted when used. The encrypted tokens remain in KV until manually removed or replaced with new authorization. The app owner controls the Worker and its configuration. We do not add these tokens or private keys to the public GitHub repository or to the static website.

How the data is used and shared

The authorization data is used only to connect the authorized TikTok account and support authorized publishing development. The app communicates with TikTok's official API and uses Cloudflare to run the server and store encrypted authorization data. The static website is hosted on GitHub Pages. Those providers may independently process normal service and network data, including IP addresses, according to their own privacy terms. We do not sell authorization data or use it for advertising.

Disconnecting and deleting data

During the development phase, the account owner can revoke this app's access in TikTok's connected-app settings, and the Worker administrator can delete owner:token from the private Cloudflare KV namespace named GONEWS_AUTH. Revoking TikTok access does not automatically delete the local encrypted record; both actions should be used for complete disconnection. If a live public service is launched, we will provide appropriate account and data removal controls before accepting outside users.

Logs, policies and updates

Cloudflare may keep service request logs according to the configuration and provider policies. Do not include TikTok passwords, authorization codes, client secrets or access tokens in support messages or GitHub issues. Any future MP4 upload and publication capability will need a policy update describing its storage, retention, removal and usage rules before launch. This privacy notice may be updated as the project evolves.

Project contact

This project is managed by the repository owner, Danifloo. For general public project information, see the GitHub repository. It currently offers no dedicated private support channel. This service is not affiliated with TikTok.
