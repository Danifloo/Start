Generar clave de cifrado

Esta herramienta genera los 32 bytes aleatorios requeridos para TOKEN_ENCRYPTION_KEY mediante la función criptográfica segura de tu navegador. La clave se genera en tu dispositivo y no se envía a ningún servidor.

1. Genera tu clave

Pulsa el botón para generar la clave.

2. Guárdala en Cloudflare

En Cloudflare abre gonews-tiktok-auth → Settings → Runtime variables and secrets → Add variable. Usa la clave de variable TOKEN_ENCRYPTION_KEY, el tipo Secret y pega el valor que acabas de generar. Pulsa Add 1 variable and deploy.

Importante: no publiques esta clave en GitHub, no la pegues en el chat y no la fotografíes. Guárdala en tu gestor de contraseñas. Si la pierdes o la cambias, las autorizaciones cifradas anteriormente dejarán de poder leerse y habrá que volver a conectar TikTok.
