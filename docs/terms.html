About this website

GoNews Publisher is an experimental owner-only project. This static website provides public information and local MP4 preparation. A deployed, protected Cloudflare Worker supports Sandbox OAuth account linking and a private preparation panel. Publishing is disabled by configuration. Sandbox authorization does not grant public posting rights; the latest supplied TikTok dashboard screenshot shows Production: Draft. This is not a launched public service.

Content rights and consent

Any future service will be intended for the TikTok account owner to publish only content they are authorized to distribute, with clear approval for individual submissions. Users must comply with TikTok's platform terms, API guidelines, content rules, music licensing and applicable laws.

No circumvention

The project is not a means to bypass TikTok account, API, posting rate or review restrictions. Unreviewed integration activity must comply with TikTok's test-mode limitations.

Current eligibility

TikTok's current review rules exclude private/personal apps and owner/team-only upload utilities from Direct Post approval. This prototype has not resolved that requirement. We do not claim approved access or a public product.

No guarantees

This project is a prototype with no uptime, delivery, earnings or publication guarantees. An uploaded video is not considered published until TikTok confirms publication.

Further information

View the source-code repository and privacy policy. A full operational agreement must be completed before a live service launches.
